# 双色球概率实验室（3 分钟新手试玩）

一个面向零基础年轻群体的**纯前端双色球科普与模拟试玩独立网页**，帮助用户在 3 分钟内看懂规则、完成虚拟选号与即时摇奖，并用多期模拟直观感受真实中奖概率。

## 在线体验
- 部署地址：`https://aka939.github.io/ssq-probability-lab/`

## 核心功能
- **¥2 宇宙分支实验（渐进式规则引导）**：三幕式互动关卡，用天文事件类比一至六等奖概率，滑块演示复式组合变化。
- **4 步侧滑无滚动试玩台**：支持左右侧滑切换「选 6 红 + 1 蓝 → 亮灯看奖级 → Crystalized Ball 水晶球摇奖 → 百期概率实验」。
- **零成本虚拟体验金**：默认赠送 100 虚拟币（可随时免费补币），基于 `LocalStorage` 本地保存余额与最近 20 条试玩记录，支持 URL 参数分享选号。
- **百期模拟器 & Holo 全息战绩卡**：毫秒级模拟 50/100 期开奖分布，自动生成带称号的 3D 全息战绩卡片。

## 技术架构
采用单文件纯前端四层架构（接入层 → 编排层 → 服务层 → 数据层），基于原生 HTML5 Canvas、Web Audio 合成音效、Web Crypto API 无偏随机摇奖与 Tailwind CSS 构建，无需后端服务器即可离线/在线运行。
