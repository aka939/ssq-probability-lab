# 双色球概率实验室（Double Color Ball Probability Lab）

一个面向零基础新手的**双色球科普与模拟试玩单页应用**，帮助从未接触过彩票的用户在三分钟内看懂玩法规则、感受真实数学概率，并体验完整的模拟选号与开奖闭环。

## 在线体验

- 部署地址：https://aka939.github.io/ssq-probability-lab/ （电脑与手机浏览器均可直接访问）

## 核心功能

1. **渐进式规则探险（`EXP-01` ~ `EXP-03`）**
   - **EXP-01 样本构成**：用“¥2 宇宙分支实验”微故事带出 `6 红 + 1 蓝` 选号规则与蓝球保底机制（点击激活 08 号蓝球解锁）。
   - **EXP-02 概率尺度**：展示 6 个官方奖级与精确数学概率（总中奖率约 6.71%，一等奖 `1 / 17,721,088`），并将每个奖级类比为小行星撞击、双中子星并合等宇宙尺度事件。
   - **EXP-03 组合放大器**：通过交互滑块直观演示“复式”与“胆拖”如何按组合数拆分注数与花费。
2. **双端同屏模拟试玩盘**
   - 支持 **单式 / 复式 / 胆拖** 三种投注模式，带胆拖动态填空引导与新手一键示例。
   - 桌面端采用**左右分栏**（左选号、右悬停摇奖对比），手机端配**底部吸底开奖栏**与正圆 3D 球体网格，确保双端零门槛操作。
   - **Crystalized Ball 电磁球漏球动画**：开奖时 6 红 1 蓝逐颗跳出并与已选号码实时比对，配 Web Audio API 合成交互音效（支持右上角一键静音）。
   - **百期加速器**：一键模拟连买 100 期（固定投入 ¥200），通过 Chart.js 柱状图对比实测命中次数与理论期望。
3. **全息趣味战绩卡**
   - 根据试玩数据生成实验称号（`物理绝缘体`、`5元慈善家`、`小奖收割机`、`天选欧皇体验卡`），支持鼠标/触控倾斜反光预览与 PNG 图片导出。

## 快速部署上线

本项目为纯前端静态页面，无需后端服务或构建步骤；**三个第三方依赖已全部本地化到 `vendor/`，断网也能完整运行**（选号、摇奖、音效、百期图表均可用）：

- **本地离线**：直接双击 `index.html`（`file://`）打开即可，无需网络、无需起服务。
- **GitHub Pages**：将本仓库上传至 GitHub 后，进入 `Settings → Pages`，选择 `Deploy from a branch`（`main` 分支根目录 `/`）即可生成免费 HTTPS 链接。
- **腾讯云 EdgeOne Pages**：在腾讯云控制台进入 `EdgeOne → Pages`，直接上传本文件夹或关联本 GitHub 仓库，输出目录填 `.` 即可免费部署并获得全球加速域名。
